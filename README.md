# Erik — Digital Portfolio

> A personal digital portfolio built with Next.js, React, and TypeScript.

A focused portfolio experience for presenting frontend development work, selected projects, technical skills, and professional information through a custom responsive interface.

## Highlights

- Next.js App Router
- TypeScript-first development
- Responsive portfolio architecture
- Custom visual presentation
- Structured project and asset organization
- Production-ready Next.js build

## Tech Stack

Next.js 16 · React 19 · TypeScript · CSS · Vercel

## Getting Started

```bash
npm install
npm run dev
npm run build
npm start
```
